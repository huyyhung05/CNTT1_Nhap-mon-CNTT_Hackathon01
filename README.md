# Website trung tâm ngoại ngữ

Đây là thư mục quản lý tài liệu cho **website trung tâm ngoại ngữ**. Các file được sắp xếp lại để *dễ tìm và sử dụng*.

## Cấu trúc thư mục

| Thư mục | Nội dung |
| --- | --- |
| `docs` | Thời khóa biểu |
| `media` | Logo trung tâm |
| `data` | Bảng đăng ký học Excel |
| `logs` | Log và các file báo cáo |
| `backup` | Bản sao logo |

## Lệnh xem toàn bộ file

```powershell
Get-ChildItem -Recurse -Force
```
